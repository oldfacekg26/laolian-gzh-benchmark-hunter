# 赛道大类词 → 关键词

目标：拿到一个大类词（中老年、读书、职场、心灵鸡汤、AI…），输出 **5-10 个**关键词，每个都能在 wxrank 里真正搜到高阅读文章。

## 出词方法：四件套拼词

一个大类词往四个方向展开，再从四个方向里各挑几个：

| 词族 | 作用 | 例子（以「中老年」为例） |
|---|---|---|
| 人群词 | 锁定是谁在看 | 中老年、退休、60后、退休老人、中老年女性 |
| 场景词 | 锁定什么时候看 | 退休生活、养老、带孙子、独居、看病 |
| 痛点词 | 锁定为什么点开 | 孤独、被子女嫌弃、养老金、慢性病、失眠 |
| 结果词 | 锁定想要什么 | 养生秘诀、晚年幸福、长寿、心态好、体面养老 |

**只挑词，不挑句子。** wxrank 是标题/正文关键词匹配，长句命中率反而低。

## 选题的硬要求

1. **数量 5-10 个**。少于 5 个池子太小；多于 10 个花钱多、重复率高。
2. **覆盖至少 3 个词族**。全是人群词会搜出一堆泛号，全是痛点词会跑偏到情感号。
3. **避开过宽词**：「生活」「情感」「人生」这种词搜出来的是全网大号，判不出赛道。
4. **避开纯品牌词**：品牌名只能搜到官方号，不是对标对象。
5. **每个词都要能解释**：「为什么这个词能挖到对标」——解释不了就换掉。

## 每个词必须带一句说明

输出格式：

```
1. 退休生活 —— 赛道最核心的场景词，覆盖「退休第一年」这类高频选题
2. 养老金 —— 痛点+政策交叉，评论区讨论最集中
3. 独居老人 —— 人群+场景，容易命中低粉账号的情绪爆款
```

说明要写"为什么"，不要写"这个词很热门"这种空话。

## 冷门赛道要调低门槛

如果关键词搜出来的池子很小（比如不到 30 篇），说明赛道冷：

- 把 `--min-read` 从 1000 降到 **300**
- 把 `--months` 从 6 拉到 **12**
- 把 `--pages` 从 3 提到 **5**

反过来，如果池子大得离谱（上万篇），把 `--min-read` 提到 3000，先看头部。
