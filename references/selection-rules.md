# 对标账号 + 爆款文章的判定口径

这套口径是全流程的准绳。改口径就改这里的数字，别在脚本里各处硬改。

## 一、什么算「值得对标的账号」

### 爆款倍率（核心代理指标）

```
爆款倍率 = 该号在池内的最高阅读 ÷ 该号在池内的阅读中位
```

倍率越高，说明这个号**整体量级不高，但偶尔有一篇打爆**——这正是新手最该抄的对象（内容力，而不是账号体量）。

### 标记规则

满足任一条即标记「低粉爆款信号」：

- 倍率 ≥ 3 且最高阅读 ≥ 10000
- 最高阅读 ≥ 100000（不管倍率）

阈值可用 `--signal-ratio`、`--signal-read` 调整。

### 必须写明的三件事

1. **粉丝数一律写「不可见」**。wxrank 不提供粉丝数，任何"低粉"的说法都是代理推断，不是事实。
2. **「池内篇数」是被截断的值**。`artlist` 只回流高于阅读下限的文章，池子里只有 2 篇不代表这个号只发过 2 篇。
3. **中位数只在这批高阅读文章里算**。所以倍率是"保守偏低"的估法，真实倍率可能更高。

## 二、什么算「值得下载学习的爆款文章」

按顺序过六道：

| # | 规则 | 默认值 | 参数 |
|---|---|---|---|
| 1 | 时间窗：发布时间在近 N 个月内 | 近 6 个月 | `--months` / `--since` |
| 2 | 阅读下限：低于此值不进候选 | 1000（冷门赛道 300） | `--min-read` |
| 3 | 赛道相关性：标题或摘要必须命中赛道词 | 用第 2 步定稿的关键词 | `--must` |
| 4 | 去重：`sn` 和标题双重去重 | 开 | — |
| 5 | 排序：爆款分从高到低 | 阅读×1 + 转发×3 | `--w-read` / `--w-share` / `--w-look` / `--w-like` |
| 6 | 每号上限：防止一个号刷满清单 | 每号 5 篇 | `--per-account` |

### 爆款分公式

```
爆款分 = 阅读 × w_read + 转发 × w_share + 在看 × w_look + 点赞 × w_like
默认： 阅读 × 1    + 转发 × 3      + 在看 × 0     + 点赞 × 0
```

转发权重给到 3，是因为转发代表"愿意为它背书"，比点赞更能说明内容真的有用。

### 低粉爆款优先配额

`--prefer-low-fan`（默认开）时，先用「带低粉爆款信号的账号」填满总篇数的 60%（`--low-fan-quota`），再按爆款分填满剩下的 40%。

这样既保证清单里有"小号打爆"的样本，也不会全是低量级内容。

## 三、默认值速查

| 参数 | 默认 | 说明 |
|---|---|---|
| `--months` | 6 | 时间窗 |
| `--pages` | 3 | 每个关键词每个月翻几页 |
| `--min-read` | 1000 | 冷门赛道降到 300 |
| `--per-account` | 5 | 每号最多几篇 |
| `--total` | 50 | 总下载篇数 |
| `--low-fan-quota` | 0.6 | 低粉爆款账号占的名额比例 |
| `--signal-ratio` | 3 | 倍率阈值 |
| `--signal-read` | 10000 | 触发信号的阅读门槛 |
| `--max-yuan` | 10 | 单轮付费上限（脚本硬停） |

篇数和每号上限**要问用户**，但用户没特别要求时就用这两个默认值。

## 四、必须留给用户拍板的三道卡

1. **关键词卡**：第 2 步出词后，等用户增删改，定稿才动手。
2. **账号卡**：第 3 步出完账号名单，停下给用户过目（可用 `--only-accounts` / `--exclude-account` 落地他的增删）。
3. **文章卡**：第 4 步出完文章清单（`picked.md`），停下给用户过目，确认后再下载（可用 `--only-sn` 只下指定几篇）。

不要跳过任何一道。用户不满意就回到对应步骤重跑，不要"先下下来再说"。
