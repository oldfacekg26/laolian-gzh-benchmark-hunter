# 对标账号与爆款文章判定规则

## 发现与核查分开

1. 用已授权的赛道词找阅读至少 10000 的候选文章。关键词池仅负责发现，不能充当账号日常阅读基线。
2. 从文章取得 wx_biz，按号查询普通文章：去掉关键词、min_read_num=0，不设置最高阅读门槛。使用 cursor 翻页，空列表或无 cursor 停止。
3. 默认基线窗口是该号最新相关过万内容发布日及之前 30 天。基线只采用与该候选相同的 content_type（如 article、book）；不同类型的文章需要各自基线。历史爆款使用当时窗口，不能把旧爆款与账号现在的中位数混算。
4. 按账号与 sn 或稳定永久链去重。真实零阅读计入；缺失、空值、非数值不当作 0。偶数样本中位数取中间两项平均。

## 低日常阅读爆款信号

以下条件同时成立：

- 普通文章基线有至少 10 条有效阅读。
- 基线中位数大于 0 且低于 1000。
- 对应单篇文章在同一基线窗口内，阅读至少 10000。
- 单篇阅读 ÷ 基线中位数至少 10 倍。

这是低日常阅读的代理信号；粉丝数不可见，不能声称已经核实真实低粉。十万阅读也必须满足低中位数和有效样本条件，不再无条件标记。

基线不够、仅取得高阅读文章或中位数为 0 时，写待核实，不凑数。接口有 content_type 时默认比较同类型。无类型或缺失时明确样本类型未知，不能写成纯长图文表现，也不能把混合中位数当作已验证的同类型信号。行业宣传、机构新闻等数学达标账号还需检查内容与目标赛道是否适合对标。

## 账号与文章分别判断

账号报告显示基线起止日、实际样本日期、总篇数、有效阅读篇数、缺失篇数、均读、中位数、最高阅读及相关爆款倍率。最高阅读未必属于目标赛道；代表作必须是相关且单篇达标的文章。

选文章逐篇判断，不能把该账号的所有文章都标成低粉爆款。只在相同基线窗口内计算单篇倍率。不同窗口的文章需重新取对应基线才能判定。

默认选文保持阅读×1＋转发×3排序；低日常阅读信号优先，但未验证的文章不会继承账号标签。默认总量 50、每号 5；用户允许按需调整时执行其要求，total=0 或 per-account=0 表示不设对应数量上限。only-low 仅输出单篇达标文章。

## 统计与完整度

所有均读和中位数都称为样本指标。库覆盖、分页上限、预算截断不等于账号全量。关键词池均读不能写全量月均。10万＋按接口数值下界统计，并标注截断；实时峰值不和离线中位数混算新的精确倍率。

## 默认参数

| 参数 | 默认 | 作用 |
|---|---:|---|
| months | 6 | 发现候选的月份范围 |
| pages | 3 | 关键词每月最多页数 |
| min-read | 10000 | 发现候选文章门槛 |
| baseline-days | 30 | 候选发布日及之前天数 |
| baseline-pages | 3 | 按号每月最多页数 |
| baseline-min-samples | 10 | 基线有效阅读样本下限 |
| baseline-median-max | 1000 | 中位数必须严格低于此值 |
| signal-read | 10000 | 单篇爆款阅读门槛 |
| signal-ratio | 10 | 单篇倍率门槛 |
| verify-top | 80 | 最多核查候选账号数 |
| target-accounts | 0 | 非零时取得此数量命名信号账号即可停止核查 |
| max-yuan | 15 | 累计保守记账硬上限；不是付费授权 |
| total | 50 | 选文总量，0 不限制 |
| per-account | 5 | 每号篇数，0 不限制 |

先不加 --yes 看计划，拿到本轮授权再查询。resume 复用同一输出目录的发现池、查询缓存与账本，不把续跑当新预算；spent-before 可计入前一轮支出。改关键词或发现条件时换输出目录，避免误用搜索缓存。失败业务响应不当产出。

默认关键词、账号、文章清单都给用户过目；用户明确授权自主扩词与按需选文时连续完成清单。下载正文仍需明确同意。
