# 微信读书搜索备选（免费候选发现）

路线实测日期：2026-10-08。文档更新：2026-10-09。

用于公众号文章的低频搜索、日期筛选与原文直链核对。wxrank 仍是本 Skill 的真实阅读核查与爆款判断主路线。

## 何时使用

- 用户明确指定微信读书、免费搜索，或不用 Key 找近期文章。
- wxrank 搜索不可用、没有 Key，或已有候选不足，需要免费补充文章。先说明切换及其范围，再完成已授权的搜索。
- 用户只有公众号名而缺文章链接时，可搜索名字寻找入口，但必须打开文章核对来源；名字命中不证明属于该号，更不代表该号全部历史。

不检查 wxrank Key、不调用付费接口。结果统一称“候选文章”；缺少可靠阅读和普通文章基线时，不输出爆款、低粉、均读或倍率结论。要补真实阅读，另按主流程说明计划并取得付费授权。

## 浏览器流程

使用当前环境已提供的浏览器工具及其文档。这里记录的是页面流程，不要求安装原项目的 agent-browser，也不预设浏览器 ID 或工具方法名。

1. **确认关键词与时间窗。** 用户已指定关键词或授权扩词时直接使用；否则按主 Skill 的关键词确认规则。默认近 7 天，用户指定日期优先。一次一个关键词，默认每词最多查看 30 条已加载结果，够用即停；搜索结果不代表完整覆盖。
2. **复用登录态。** 查看当前浏览器与标签，优先复用 [微信读书网页版](https://weread.qq.com/) 登录态。确实需要登录时显示二维码，请用户用手机微信扫码并确认，完成后继续。保持该浏览器中的微信读书标签打开；不读取、导出 Cookie 或凭据，不清空登录状态，不关闭用户标签。
3. **进入搜一搜。** 使用同一浏览器，按已验证入口打开搜索页，`query` 使用关键词的 URL 编码：

   ```text
   https://search.weixin.qq.com/cgi-bin/newsearchweb/userclientjump?path=page/search/weread&query=<URL编码后的关键词>&platform=pc
   ```

   实测例：[搜索“大模型”](https://search.weixin.qq.com/cgi-bin/newsearchweb/userclientjump?path=page/search/weread&query=%E5%A4%A7%E6%A8%A1%E5%9E%8B&platform=pc)。入口可能变化，若失效应读取当前页面判断，不猜造替代接口。
4. **筛文章与日期。** 读取实际渲染的标题、来源公众号、搜索页日期及条目 ID；过滤百科等非文章结果。需要更多候选时缓慢滚动加载、重新查看页面，逐页去重。默认顺序混合新旧文章，不能把前几条当最新榜。以采集时间为参照记录“几小时前 / 几天前”；无法确认日期时标“待核实”，不纳入已核实时间窗。
5. **逐条点击核对。** 用页面交互打开拟交付候选，通过实际跳转或新标签取得完整 `mp.weixin.qq.com` URL，核对正文标题、公众号与发布时间，再决定是否保留。保留真实地址全部参数及片段（如 `__biz`、`mid`、`idx`、`sn`、`chksm`、`#rd`），不截短、不拼接。按条目 ID 或文章身份（如 `__biz + mid + idx` / `sn`）去重；同标题的不同文章不自动合并。未打开成功的单独标“待核实”，不能计入成功数。
6. **交付候选，等下载确认。** 按下节格式保存候选表；对用户确认要下载的条目生成一行一链的 `weread-links.txt`，接主 Skill 功能 ② 免费下载。搜索候选阶段只做核对，不整篇归档正文与配图。结束时仅关闭本次创建的搜索或文章临时标签，保留用户登录页。

实测页面曾使用 `.search_list_item`、`.article__title-text`、`.source__title`、`.source__text.date` 与条目 `data-id` 读取信息。这些只作为定位提示；先查看当前页面，结构变化时以实际内容为准，不对空结果套用旧选择器后宣称无文章。

## 候选交付与免费下载

在用户指定输出目录保存 `weread-candidates.md`，记录关键词、采集时间、时间窗、已加载条目数、过滤与核对成功数，并用下列表格交付：

| 标题 | 来源公众号 | 搜索页日期 | 正文发布时间 | 完整原文链接 | 核对状态 |
|---|---|---|---|---|---|

正文发布时间以文章页面为准；无法确认则留空或标“待核实”。阅读量、样本均读、中位数和倍率留空，粉丝数标“不可见”。即使搜索页出现粗略阅读显示，本次也没有核验其精度和覆盖率，不能据此排名。明确披露关键词池与加载上限，不称全量、最新榜或账号全部文章。

文章清单获用户下载确认后，把获准且已核对的完整链接写入 `<输出目录>/weread-links.txt`，调用已有命令：

```powershell
node "<SKILL目录>\scripts\download.mjs" --out "<输出目录>" --links "<输出目录>\weread-links.txt"
```

不加 `--allow-paid`，不把自定义候选 JSON 传给期待特定格式的 `--from`。链接模式下载归档会标“手动链接清单（无阅读量数据）”；保留 `weread-candidates.md` 记录微信读书搜索来源。

## 停止与恢复

浏览器工具超时不等于搜索失败：先查看现有标签和页面状态，可做一次正常刷新或重新绑定；不要重复创建相同标签。仍不可读时报告已取得的候选及未完成部分。登录失效时请用户重新扫码；遇到验证、访问限制或持续无结果时停止该路线，不加量重试，不自动切付费，不重启浏览器或清理 Cookie。
